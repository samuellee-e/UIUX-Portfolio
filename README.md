# 🎨 UI/UX Portfolio

A modern, responsive portfolio website showcasing my UI/UX design projects, design process, and frontend development skills. This portfolio highlights my work in user-centred design, interactive prototypes, and mobile/web application interfaces.

🌐 **Live Demo:** https://samuellee-e.github.io/UIUX-Portfolio/

---

## 📖 Overview

This portfolio was created to present my UI/UX projects in a clean, engaging, and accessible format. It demonstrates my approach to solving design problems through research, wireframing, prototyping, and visual design while also showcasing my frontend development capabilities.

The website is fully responsive and designed to provide an intuitive browsing experience across desktop, tablet, and mobile devices.

---

## ✨ Features

- Responsive design for all screen sizes
- Modern and minimalist user interface
- Smooth scrolling and interactive animations
- Project showcase with detailed case studies
- Skills and technologies section
- Contact information for recruiters and collaborators
- Optimised for performance and accessibility

## 🚀 Running the Project Locally

1. Clone the repository

```bash
git clone https://github.com/samuellee-e/UIUX-Portfolio.git
```

2. Navigate into the project folder

```bash
cd UIUX-Portfolio
```

3. Open `index.html` in your browser

or use a local development server such as:

```bash
python -m http.server
```
